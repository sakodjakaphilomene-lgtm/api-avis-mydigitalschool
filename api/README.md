# API Avis MyDigitalSchool

## Description

API REST développée avec Node.js, Express, Prisma et PostgreSQL permettant la gestion des avis utilisateurs.

## Fonctionnalités

* Afficher tous les avis
* Afficher un avis par ID
* Ajouter un avis
* Autoriser un avis
* Supprimer un avis
* Inscription utilisateur
* Connexion utilisateur
* Réinitialisation de mot de passe
* Envoi d'email avec Nodemailer

## Technologies

* Node.js
* Express
* PostgreSQL
* Prisma
* Argon2
* Nodemailer

## Installation

```bash
npm install
npm start
```
